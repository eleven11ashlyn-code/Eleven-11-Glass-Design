ELEVEN:11 — DEPLOYMENT PACKAGE

Upload all contents of this ZIP to your static hosting document root.
index.html must sit at the root alongside styles.css, app.js,
dock-motion.mjs, and the assets folder.

No build step, npm installation, API key or server-side runtime is needed.
Serve JavaScript modules (.js and .mjs) with a JavaScript MIME type.
For a local preview: python3 -m http.server 8000
Then visit http://localhost:8000 (do not open index.html with file://).

This export includes the latest translucent navbar, brand logo,
blue/teal colours, product concept visuals, and fluid navigation.

The enquiry form prepares an email or WhatsApp message for the visitor
to review and send. It does not submit to or store messages on a backend.
Portfolio links point to the existing Eleven:11 website.
Hero product visuals are AI-generated concepts, not client project claims.

ChatGPT preview access restrictions do not travel with this ZIP.
Configure access separately on your chosen host if you want a private site.
