ELEVEN:11 — DESIGN-FIRST AGENTIC DEVELOPMENT

Unzip the whole folder, then open index.html in a modern browser.
No installation, server, internet connection or API key is required.
Keep index.html, styles.css, app.js and the assets folder together.

PRESENTING
Use Next / Previous, Left / Right arrow keys or Page Up / Page Down.
Use Slides to jump to any section. You can also scroll normally.
Use Present fullscreen on supported desktop browsers; Esc exits fullscreen.
On mobile, scroll or use the floating presentation controls.

CONTENT
13 slides cover design direction, agentic implementation, websites,
web apps, mobile apps, team responsibilities, a proposed 90-day transition,
quality checks, measurement and a proposed Eleven:11 pilot.
The rollout is a proposal, not a claim about the company's current process.
No fixed speed or cost improvement is promised.

EDITING / HOSTING
Edit text in index.html, appearance in styles.css and navigation in app.js.
Upload these files to any static web host if you want a shareable web URL.
All assets are local. There are no forms, tracking services or external requests.
